Statistical toolkit

Five checks, each with a clear job

Every number the agent reports comes from one of these functions, never from the language model.

Trend evaluation

Is the signal steadily drifting or stationary?

normalised polyfit · m/σ

Stationarity

Has volatility changed between the first and second half?

split-half variance ratio σ₂²/σ₁²

Changepoint detection

Finds abrupt shifts and sensor resets.

z-score on first differences · CUSUM proxy

Multicollinearity

Flags redundant feature pairs for pruning or PCA.

Pearson matrix · |r| ≥ 0.70

Outlier scoring

Isolates non-Gaussian spikes.

Q1 − 1.5×IQR … Q3 + 1.5×IQR

Usage

Three lines to a report

The agent returns a full Markdown report ready to read or share.

  • Profiles shape, types, null rates and duplicates
  • Runs every statistical check deterministically
  • Suggests preprocessing and a model family (e.g. LightGBM vs. XGBoost)
