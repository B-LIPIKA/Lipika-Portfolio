Core idea

Two layers, one hard boundary

Hallucination is the biggest risk when AI touches industrial data. The fix is architectural: keep reasoning and arithmetic apart.

⚡ Deterministic layer

  • Schema discovery & read-only SQL
  • Mean, min, max, median, std-dev
  • ISO vibration & temperature thresholds
  • Linear trend and drift rate

Exact, repeatable, testable.

🧠 Reasoning layer

  • Understands the engineer's question
  • Picks equipment, metric and time range
  • Reads the evidence payload
  • Writes a diagnostic report and recommendation

Only ever interprets numbers it was given.
